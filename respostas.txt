Exercício 3 A função abaixo deveria contar quantos pedidos existem em cada situação. Responda sem rodar o código primeiro: 

a) O que ela retorna para a chamada do exemplo?

Retorna 

  Aberto: 0,
  Faturado: 0

b) Quais são os problemas? Explique com as suas palavras.

O laço começa errado: ele começa no i = 1, então acaba pulando o primeiro pedido. O certo é começar no i = 0 para contar todos.
O outro problema é que o código faz a soma, mas não guarda o resultado, então o valor continua o mesmo. 
Se usarmos resumo[s] + 1, a conta é realizada, mas o resultado não é armazenado, fazendo com que o valor continue sendo 0.
O certo seria usar resumo[s] = resumo[s] + 1, que soma 1 ao valor anterior e atualiza a contagem sempre que encontrar um pedido daquela situação.

c) Escreva a versão corrigida. (Depois disso, pode rodar para conferir.)

function contarPorSituacao(pedidos) {
  let resumo = {};

  for (let i = 0; i < pedidos.length; i++) {
    let s = pedidos[i].situacao;

    if (resumo[s] == undefined) {
      resumo[s] = 0;
    }

    resumo[s] = resumo[s] + 1;
  }

  return resumo;
}
